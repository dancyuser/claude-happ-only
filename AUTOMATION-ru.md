# Автоматическая установка AppID и проверка покрытия

Этот вариант пока является предварительным выпуском. Сценарии установки и отказов проверены с подменой системных операций; применение новой AppID-политики на чистом Windows 11 и полный прогон с UAC остаются отдельными проверками. Установщик не запускает и не завершает Claude.

## Обычная установка

Распакуйте весь комплект, самостоятельно закройте Desktop и Code, запустите `Install.cmd` обычным пользователем. Мастер запрашивает адрес сервера Happ, его порт, локальный порт прокси, страну выхода и физический адаптер. Для MSIX по умолчанию включен `AppIdMode=Auto`. Компилятор ConfigCI при необходимости устанавливается в профиль пользователя из подписанного компонента самой Windows. Если подходящего компонента нет, установка останавливается с ошибкой.

Один административный процесс выполняет инвентаризацию политик, установку или повторное использование подходящей политики, резервное копирование защиты, Install/Fix и итоговый Preflight. Необязательный Browser Tamer может запросить собственный UAC. Примененная политика должна обнаружиться как активная с ожидаемым SHA256; иначе разрешение запуска не выдается. Если Windows требует перезагрузки, выводится `PendingActivation`: перезагрузитесь самостоятельно и повторите установку.

Для существующей установки запустите из каталога распакованного комплекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-CodeSupport.ps1
```

Для предварительного просмотра без изменений:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Automated.ps1 -ConfigurationFile "$env:ProgramData\ClaudeHappOnly\config.json" -Mode Fix -Preview
```

Для проверки существующей политики с явным запретом установки новой:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Automated.ps1 -ConfigurationFile "$env:ProgramData\ClaudeHappOnly\config.json" -Mode Fix -PreserveExistingPolicyOnly
```

`Auto` включает AppID для MSIX. `Require` отказывает для отдельной установки без MSIX. `Off` оставляет ограничения по известным исполняемым файлам и не заявляет защиты через AppID. Переключатель передается в Setup/Update как `-AppIdMode Auto`, `Require` или `Off`. `-NoWatch` отключает только наблюдатель покрытия.

## Проверка перед запуском

Ярлык по-прежнему выполняет свежий Preflight перед каждым пользовательским запуском. Проверяются туннель и ограничения тестовой программой. При обязательном AppID дополнительно проверяются действующая политика и ее отпечаток. Краткоживущий билет привязан к пользователю, конфигурации, исполняемому файлу и защищенной записи AppID. Успешная установка не заменяет эту проверку при следующем запуске.

## Наблюдение за дочерними процессами

После успешной установки наблюдатель ждет вашего ручного запуска до 10 минут. После появления процессов он наблюдает их до двух минут в пределах общего лимита. Наблюдатель также включается при обычном пользовательском запуске через ярлык. Он читает токены и пишет локальный отчет; процессы не изменяет.

Откройте `Status.cmd` в комплекте. Отчет покрытия находится в `%LOCALAPPDATA%\ClaudeHappOnly\Coverage\latest.json`:

| Статус | Значение |
| --- | --- |
| WaitingForUserLaunch | Процессы не найдены; покрытия пока не проверено |
| ObservedProcessesTagged | Все доступные процессы текущего снимка имеют тег |
| CoverageGap | Найден процесс без тега; в Rows указан конкретный процесс |
| Unknown / ObserverError | Проверка неполна или завершилась ошибкой |

`ObservedProcessesTagged` относится только к наблюдавшемуся снимку. Это не гарантия для будущих, быстро завершившихся, недоступных процессов или работы в VM/WSL. Ранее обнаруженный conhost без тега автоматически не становится защищенным от установки политики. Наблюдатель выявляет разрыв покрытия, но не может безопасно добавить тег существующему токену. Он не подменяет сетевую блокировку и не является разрешением запуска. Для гарантии произвольного дерева процессов нужен отдельный механизм изоляции или перехвата создания процессов с блокировкой до начала исполнения; он в этом выпуске не реализован.

## Резервные копии и откат ошибки

Административный журнал хранится в `%ProgramData%\ClaudeHappTransactions\<GUID>`. Он содержит план, кандидата конфигурации, состояние и результат. Доступ на запись ограничен администраторами и SYSTEM. Не публикуйте этот каталог: в нем локальные параметры.

При ошибке установщик пытается восстановить предыдущую защиту из своей резервной копии и пользовательские настройки Code. Только созданную этой транзакцией AppID-политику можно удалить автоматически, после повторного сравнения ее SHA256. Существующая политика сохраняется. Чужая или изменившаяся политика не перезаписывается и не удаляется. Полный firewall не сбрасывается.

Это компенсирующий откат отдельных операций, а не общая атомарная транзакция Windows. Если восстановление не удалось, результат содержит `NeedsReview`. При первой установке уже созданные сетевые ограничения сохраняются для ручного разбора, а не снимаются автоматически. `guard-retained.txt` и `GuardDisposition` фиксируют этот случай. До устранения ошибки не используйте обычный запуск.

`Restore.cmd` восстанавливает резервную копию сетевой защиты по существующей инструкции. Самостоятельное удаление успешно установленной AppID-политики выполняется отдельно по `APPID-ru.md`; Restore не должен удалять ранее существовавшие политики. Сначала переведите конфигурацию в явно выбранный режим без обязательного AppID и проверьте защиту. Не удаляйте политику, на которую еще опирается текущая конфигурация.

## Если что-то не работает

- Ошибка компилятора: запустите `Install-ConfigCI.ps1 -Mode Check`; не скачивайте случайные DLL.
- `APPID_ID_CONFLICT` / `APPID_LEGACY_REVIEW`: сохраните отчет. Требуется ручная проверка содержимого политики; автоматической перезаписи нет.
- `APPID_NOT_ACTIVE_OR_CHANGED`: повторите установку после проверки текущих политик; не меняйте вручную отпечаток в защищенном состоянии.
- Ошибка прокси или страны: проверьте выбранный only WiFi в Happ и поля мастера. Настройте правильный локальный порт, не разрешайте запасной прямой выход.
- `CoverageGap`: изучите Rows. Для дополнительного EXE нужна отдельная проверка и правило либо изоляция; разрешение всей папки системных программ не исправляет наследование тега.

Не присылайте публично полный журнал, конфигурацию или резервные копии. Они могут содержать SID, пути и адреса вашего сервера.
