# Ссылки Claude и Google в выделенном профиле Chrome

Эта инструкция касается выбора браузерного профиля. Если в выделенном профиле уже настроены расширения для прокси Happ, **их менять не требуется**. Browser Tamer не является сетевым VPN/прокси: он выбирает, кому передать внешнюю ссылку.

## Установка

Запустите `Install-BrowserTamer.cmd` либо согласитесь на необязательный шаг после установки защиты. Загрузчик получает актуальный стабильный MSI Windows x64 из официального `aloneguid/bt/releases/latest`, сверяет GitHub SHA256 и открывает исходный MSI с обычным интерфейсом. Он не перезагружает компьютер автоматически и не назначает Browser Tamer браузером по умолчанию самостоятельно.

Без установки: `Install-BrowserTamer.ps1 -Mode DownloadOnly`. Кэш и verified-release.json находятся в `%LOCALAPPDATA%\ClaudeHappOnly\Downloads\BrowserTamer`. Режим VerifyOnly повторно сверяет кэш с выбранным официальным выпуском. Если Latest сменился, сначала требуется скачать новую версию.

## Правила

1. Откройте Browser Tamer. Через Windows Settings назначьте его обработчиком веб-ссылок по умолчанию.
2. Среди обнаруженных браузеров и профилей выберите Chrome → **CLAUDE**. Отображаемое имя и каталог профиля — разные вещи. Узнать каталог можно в `chrome://version`, поле Profile Path; например, имя CLAUDE может соответствовать `Profile 1`.
3. Для этого профиля добавьте правило по **имени исходного процесса** `claude.exe`, с приоритетом выше общих правил. Тогда ссылка входа через Google, переданная приложением Claude, попадёт в нужный профиль, даже если первый домен — accounts.google.com.
4. Дополнительно направьте сам домен claude.ai и его поддомены в этот профиль. Не направляйте автоматически все домены Google в CLAUDE: это изменило бы другие входы через Google.
5. Включите Picker → **On no rule**, если при неопределённом источнике нужен выбор профиля вместо автоматического открытия в основном. Это может показывать выбор и для других ссылок без правил.
6. Сохраните настройки. Проверить сопоставление можно через Tools → Pipeline debugger, не открывая настоящий OAuth URL. Используйте искусственный адрес и источник claude.exe; реальные ссылки авторизации не публикуйте в issue или журнале репозитория.

Сведения об исходном процессе доступны не всегда: Windows может передавать ссылку через посредника. При таком случае используйте выбор профиля. Это не абсолютный запрет открытия сайта другими способами. Переходы внутри уже открытого браузера также не обязаны заново проходить через системный обработчик внешних ссылок.

Наша проверка туннеля перед запуском Claude и правила выбора браузерного профиля — отдельные механизмы. Назначение профиля не расширяет сетевые разрешения Claude. Авторизация и возврат из браузера в приложение требуют отдельной ручной проверки владельцем; сам установщик Claude не запускает.

Официальные источники: [Browser Tamer: правила, профили, процесс-источник и Picker](https://www.aloneguid.uk/projects/bt/), [исходный репозиторий](https://github.com/aloneguid/bt), [параметр Chromium profile-directory](https://chromium.googlesource.com/chromium/src/+/HEAD/chrome/common/chrome_switches.h).
