# Claude Desktop через Happ — установщик Windows

Параметризованный комплект для ограничения Claude Desktop локальным SOCKS Happ, проверки туннеля перед запуском, диагностики, исправления и отката. Дополнительно умеет загружать **Browser Tamer Latest release** для открытия внешних ссылок в нужном профиле Chrome.

**Установка, Fix, Diagnose, Restore и загрузчики не запускают Claude.** Реальный запуск происходит только при самостоятельном нажатии пользователем созданного ярлыка после успешной проверки. Для проверки сценария без запуска есть `Launch-Checked.ps1 -CheckOnly`.

## Скачать актуальную версию

- [Latest release и готовый ZIP](https://github.com/dancyuser/claude-happ-only/releases/latest)
- [Прямая ссылка на ZIP](https://github.com/dancyuser/claude-happ-only/releases/latest/download/Claude-Happ-Universal.zip)
- [Загрузчик Install-Latest.ps1](https://github.com/dancyuser/claude-happ-only/releases/latest/download/Install-Latest.ps1)

Скачайте `Install-Latest.ps1`, просмотрите его и запустите локально в обычном Windows PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Latest.ps1
```

Он получает Latest release этого репозитория, проверяет ZIP по SHA256 из GitHub API, распаковывает и запускает мастер. Для загрузки **без установки, UAC и запуска программ**:

```powershell
.\Install-Latest.ps1 -DownloadOnly
```

Или распакуйте готовый ZIP и откройте `Install.cmd`. Не нужно скачивать весь Git-репозиторий. Подписку и её ключи установщик не запрашивает и не переносит.

## Требования и установка

- Windows x64, Windows PowerShell 5.1, системный curl и работающий Windows Firewall/WFP.
- Уже установленные **Happ с внутренним Xray** и Claude Desktop (MSIX либо отдельная установка с каталогом EXE).
- Happ в режиме SOCKS на `127.0.0.1`; физический адаптер с одним IPv4-адресом и шлюзом; удалённый сервер с одним согласованным публичным IPv4 и TCP-транспортом.

Мастер спрашивает имя выбранного сервера, физический адаптер, порты, страну выхода, путь к Xray и тип установки Claude. Для восстановления своей конфигурации можно передать JSON по [примеру](configuration.example.json). Для другой машины нужны её параметры; персональная конфигурация в публичный репозиторий не входит. ARM64, IPv6-only, UDP-транспорт и другие ядра Happ не поддерживаются.

Установку защиты пользователь подтверждает через UAC. Сохраняется предохранительная копия. Перед завершением выполняются статическая проверка и независимый тест curl. При неудаче ограничения не отключаются ради подключения.

## Проверяемый ярлык

`Claude - Happ Only` выполняет **Diagnose → при ошибке один Fix → повторный Diagnose → запуск только при OK**. Диагностика повышает права отдельно; Claude запускается родительским сценарием с обычным пользовательским токеном, SOCKS и отключённым QUIC.

Проверяются фильтры, текущие EXE, маршрут, адрес сервера через два независимых DNS-сервиса, задача защиты, владелец SOCKS-порта, одинаковый IP и страна выхода. Контрольный curl проверяет также запрет прямого выхода и другого локального прокси. Штатная фоновая `CoworkVMService` допускается только после проверки имени службы, LocalSystem, PID и пути из установленного пакета. Открытый клиент и неизвестные процессы отклоняются.

Предварительная проверка действует **в этом ярлыке**. Запуск через «Пуск», протокол приложения или прямой вызов EXE её не выполняет; сетевые ограничения соответствующих EXE продолжают действовать независимо от точки входа. Клиент, открытый ранее без SOCKS-параметра, нужно закрыть самостоятельно и открыть проверяемым ярлыком: Reload не добавляет параметры запуска.

Установка защиты не выбирает сервер в Happ автоматически. Используйте именно тот узел, чьё имя указано в конфигурации. Смена на другой узел может привести к штатной блокировке вместо обхода через другой VPN.

## Диагностика и восстановление

| Команда | Действие |
|---|---|
| `Install.cmd` | Настройка и установка защиты; необязательное предложение установить Browser Tamer |
| `Diagnose.cmd` | Полная проверка с curl без запуска Claude |
| `Fix.cmd` | Резервная копия, восстановление своих настроек, повторная проверка |
| `Restore.cmd -List` | Список снимков |
| `Restore.cmd -BackupId ID` | Предохранительная копия текущего состояния, откат своих настроек, диагностика |
| `Install-BrowserTamer.cmd` | Скачать и установить официальный Browser Tamer Latest release |

Рабочие файлы — `%ProgramData%\ClaudeHappOnly`, отчёты — `%ProgramData%\ClaudeHappReports`, копии — `%ProgramData%\ClaudeHappBackups`. Запись в рабочие файлы и копии разрешена Administrators/SYSTEM. Задача `\ClaudeHappOnly\Sync` поддерживает ограничения обнаруженных EXE новых версий; Claude она не запускает.

В копию входят исходники/конфигурация, собственные правила Firewall, точные WFP-фильтры, маршруты, задача и ярлыки. Полный `.wfw` сохраняется для разбора, но Restore не импортирует его целиком и не сбрасывает чужие правила. Restore не является удалением последней защиты. [Инструкция по откату](RESTORE-ru.md), [подробное руководство](GUIDE-ru.md).

## Browser Tamer и профиль Chrome

MSI не зафиксирован в архиве: загрузчик обращается к [официальному Latest release aloneguid/bt](https://github.com/aloneguid/bt/releases/latest), выбирает Windows x64 и проверяет опубликованный GitHub SHA256. Если подходящего файла или digest нет, установка отклоняется. Проверка подписи сохраняется в локальной метаинформации; совпадение SHA256 не объявляется цифровой подписью.

```powershell
.\Install-BrowserTamer.ps1 -Mode DownloadOnly
.\Install-BrowserTamer.ps1 -Mode VerifyOnly
# При необходимости выбрать конкретный официальный выпуск:
.\Install-BrowserTamer.ps1 -Version 6.3.2 -Mode DownloadOnly
```

Запуск MSI с UAC выполняется только в режиме Install по запросу пользователя. Браузер по умолчанию, маршрутизация ссылок и прокси-плагины автоматически не меняются. [Настройка профиля CLAUDE для ссылок Google/Claude](BROWSER-TAMER-ru.md).

## Проверки и ограничения доказательств

На исходной машине ранее проверены ограничения на отдельном curl, положительный выход через Happ, блокировка испытанных обходов, реальное отключение Happ, отказ допуска при недоступности прокси и контрольный откат. Сценарий ярлыка испытывался только с CheckOnly. Сетевое поведение самого Claude/Cowork, VM и внешних дочерних программ не подтверждено этим опытом. Полной гарантии отсутствия всех возможных обходов комплект не заявляет.

Для этого выпуска проверены синтаксис PowerShell, компиляция C# без вызова привилегированных API, положительные/отрицательные случаи распознавания службы и загрузка Browser Tamer без установки. **После публикации прошли UAC-проверки точного ZIP v3.2.0: Install, Fix, контрольный Restore, итоговая диагностика и проверяемый ярлык с CheckOnly.** [Состав испытания и ограничения](VALIDATION.md). Browser Tamer уже был установлен и повторно не устанавливался. Чистая установка на другой машине и обычный запуск Claude вместо CheckOnly не испытывались.

Локальные безопасные проверки: `powershell.exe -NoProfile -File .\tests\Static-Checks.ps1`. В репозитории нет персональных SID, адреса выбранного сервера, подписки, реальных резервных копий, журналов или результатов входа в Google.
