# Установка на Windows 11 x64

## 1. Подготовьте приложения

Установите Happ из [официального источника](https://happ.info/) и [Claude Desktop](https://claude.com/download). Авторизацию и подписку настройте в самих приложениях. Этот комплект не содержит серверов, учетных данных, Happ или Claude.

В Happ выберите один конкретный сервер и включите режим прокси. TUN выключите. Узнайте:

- **Домен или публичный IPv4 сервера** и **TCP-порт сервера** из параметров выбранного узла. Это не адрес подписки и не IP с сайта «мой IP».
- **Локальный порт прокси Happ**. Например, 10808. На нем должны работать SOCKS и HTTP CONNECT; адрес прослушивания — 127.0.0.1.
- **Страну выхода**, которую вы ожидаете: DE, NL и т. п. Она проверяется после подключения к серверу.

Если используете второй VPN/FlClashX, оставьте его настройки для остальных приложений. Мастер позволит указать его виртуальный интерфейс как запрещенный для Happ. Расширения прокси в Chrome менять не нужно.

Для установки нужен активный физический Ethernet/Wi-Fi с одним IPv4 и одним IPv4-шлюзом. Несколько A-записей домена, IPv6-only и UDP-серверы в этом выпуске не поддерживаются. Для домена с несколькими адресами можно явно выбрать проверенный публичный IPv4 через режим PinnedIPv4; автоматически случайный адрес не выбирается.

## 2. Скачайте комплект

Откройте [Latest release](https://github.com/dancyuser/claude-happ-only/releases/latest), скачайте `Claude-Happ-Universal.zip` и распакуйте целиком. Сохраните эту папку: из нее доступны диагностика, смена параметров и откат.

Другой вариант — скачать `Install-Latest.ps1` со страницы release, просмотреть его и запустить в обычном Windows PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Latest.ps1
```

Он скачает и проверит текущий ZIP. Для загрузки без установки и UAC добавьте `-DownloadOnly`. Исходный GitHub-репозиторий, Git, Python и Node для установки не нужны.

## 3. Запустите мастер

Полностью закройте Claude, включая трей и Code-сессии. Скрипт не закрывает его за вас. Проверенная системная CoworkVMService может оставаться запущенной: ее отдельно проверит административный этап.

Откройте `Install.cmd` обычным двойным щелчком. Не выбирайте «Запуск от имени администратора»: мастер должен определить обычного пользователя, а для системной части сам вызовет UAC.

Мастер состоит из трех групп:

| Поле | Что вводить |
|---|---|
| Сервер | Домен выбранного узла либо его публичный IPv4. Не URL подписки, не UUID/ключ |
| TCP-порт сервера | Значение из узла Happ; часто 443, но не обязательно |
| Локальный SOCKS/HTTP-порт | Фактический порт Happ; например 10808 или свой 12345 |
| Страна | Ожидаемый двухбуквенный код выхода, например DE |
| Физический адаптер | Точное имя из показанного списка, включая пробелы и локализованное имя |
| Запрещенные виртуальные адаптеры | Имена через запятую; найденный FlClashX предлагается как значение по умолчанию. Минус `-` означает пустой список |
| xray.exe | Внутренний движок Happ; типичный путь предложен. Если Happ установлен иначе, укажите реальный файл |
| Семейство MSIX | Обычно определяется у текущего пользователя; для обычного Claude оставьте найденное |
| Отдельная установка | Выберите y только для варианта без MSIX, затем задайте каталог и основной claude.exe |

SID пользователя, путь ярлыка и стандартный кэш Code рассчитываются на новом ПК. Не копируйте `config.json` из ProgramData другого компьютера.

После ввода мастер проверяет конфигурацию, вызывает UAC для установки защиты, настраивает HTTP-прокси Code с отдельной резервной копией и вызывает UAC для итогового CheckOnly. Административное окно установки закрывается само после результата; промежуточного ожидания Enter нет.

Ожидаемый итог — **SETUP PASS**, перед ним **CHECK ONLY PASS**. При отмене UAC или ошибке возможна частично установленная защита: она не отключается ради подключения. Используйте отчет и Restore; не считайте FAIL успешной установкой.

Browser Tamer предлагается отдельно и необязателен. Он нужен только для внешних ссылок в выбранный Chrome-профиль. Правила Browser Tamer, браузер по умолчанию и расширения прокси автоматически не настраиваются.

## 4. Проверьте вручную

Только вы запускаете Claude через созданный ярлык `Claude - Happ Only`. Обычный чат и вкладка Code — разные клиенты, проверьте оба. Для Code после изменения настроек создайте новую сессию; `/status`, если доступен, должен показывать `http://127.0.0.1:PORT`.

Отдельно можно проверить без открытия Claude:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:ProgramData\ClaudeHappOnly\Launch-Checked.ps1" -CheckOnly -NoPause
```

Реальное отключение Happ — отдельный ручной тест: во время доступной сессии запрос должен перестать работать; затем подключите тот же сервер. Curl fault-тест установщика перекрывает прокси только тестовому EXE и не заменяет испытание всех приложений при физическом отключении Happ.

## Установка из небольшого JSON

Скопируйте `configuration.example.json` в свой файл, замените домен и при необходимости адаптер/порты. SID и пользовательские пути можно не указывать: мастер заполнит их локально. Пустой PhysicalInterface заполняется автоматически только при одном подходящем физическом подключении; иначе впишите имя.

```powershell
# Только проверить заполненные поля: без UAC, сетевых проб и установки.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -ConfigurationFile .\my-settings.json -Preview

# Установить по этому файлу; закончится CheckOnly, не запуском Claude.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1 -ConfigurationFile .\my-settings.json
```

Preview проверяет формат и доступность указанных файлов, но не доказывает работоспособность сервера, маршрута или отсутствие конфликтующих правил.

Для фиксированного IPv4 используйте `configuration.ipv4.example.json`. Заполните UpstreamAddress реальным публичным IPv4 сервера. В режиме Hostname адрес обновляется по согласованному DNS того же домена; в PinnedIPv4 он не меняется автоматически.

| Дополнительный параметр | Значение |
|---|---|
| EndpointMode | Hostname или PinnedIPv4 |
| UpstreamHostname | Домен узла для Hostname |
| UpstreamAddress | Явный IPv4 для PinnedIPv4; не внешний выходной IP |
| ProxyPort | 1024–65534, один локальный SOCKS/HTTP-порт |
| UpstreamPort | 1–65535, TCP-порт выбранного сервера |
| PhysicalInterface | Физический интерфейс с единственным IPv4/шлюзом |
| XrayPath | Полный путь к внутреннему xray.exe Happ |
| CodeRoot | Выделенный каталог claude-code; по умолчанию пользовательский кэш Desktop |
| UseLegacyTag | По умолчанию false для новой машины. true только при уже существующей политике ClaudeProxyOnly; установщик политику не создает |
| LaunchUserSid | Можно опустить. Конфигурация с SID другого пользователя отклоняется |
| ShortcutPath | Можно опустить; учитывается системный путь рабочего стола, в том числе перенаправленный |

Локальный адрес намеренно остается `127.0.0.1`; удаленный/сетевой прокси вместо локального Happ этот установщик не поддерживает.

## Обновление и смена параметров

При уже установленной защите `Install.cmd` и загрузчик Latest по умолчанию запускают обновление с сохранением ее параметров. Claude нужно закрыть самому. Обновление выполняет резервное копирование, Fix, настройку Code и CheckOnly. На вашем работающем ПК повторная установка для чтения этой инструкции не нужна.

Чтобы сменить домен сервера, сначала посмотрите предполагаемую конфигурацию:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Reconfigure.ps1 -Server YOUR-SERVER.example.com -Preview
```

Для явного IP вместо домена укажите реальный публичный IPv4 в `-Server`. После выбора именно этого сервера в Happ, при закрытом Claude, повторите команду без `-Preview`. Будут UAC, снимок прежней защиты и CheckOnly. Из-за старого закрепленного адреса Happ может начать передавать данные только после применения новых ограничений.

Изменить ожидаемую страну можно через `Reconfigure.ps1 -ExpectedCountry NL`. Менять страну следует только если это действительно новый намеренно выбранный выход, а не для сокрытия неправильного маршрута.

`Reconfigure.ps1 -PhysicalInterface "ИМЯ" -Preview` позволяет проверить другой адаптер. При применении старый точный маршрут через другой интерфейс может вызвать отказ: автоматически он не удаляется. Нужен разбор маршрута и его владельца либо откат; подробности в troubleshooting.

**Порты и путь ядра после установки:** новая установка допускает пользовательские значения. У существующей защиты порт локального прокси, TCP-порт сервера и путь xray автоматически не мигрируются; Manage-Happ откажет до замены правил. Не редактируйте только эти значения в ProgramData и не снимайте фильтры вручную. Держите исходный порт либо подготовьте отдельную проверенную миграцию. Обычный Restore тоже не является переносом между портами или удалением защиты.

## Откат

Для системной защиты используйте `Restore.cmd -List` и `Restore.cmd -BackupId ID`. Для настроек Code — `Configure-CodeProxy.ps1 -Mode Restore -BackupId ID` в обычном PowerShell, при закрытом Claude. Эти два вида копий независимы. [Подробный состав и ограничения](RESTORE-ru.md).

Отчеты и копии содержат локальные пути, SID и сетевые адреса. Храните их локально; не добавляйте в публичный репозиторий вместе с комплектом.
