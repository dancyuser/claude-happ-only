# Сторонние проекты

## Browser Tamer

- Официальный репозиторий: https://github.com/aloneguid/bt
- Стабильный выпуск: https://github.com/aloneguid/bt/releases/latest
- Документация: https://www.aloneguid.uk/projects/bt/
- Лицензия upstream: Apache-2.0 (проверена для 6.3.2; актуальную лицензию смотрите в официальном репозитории).

Код Browser Tamer и его MSI не включены в этот репозиторий. Install-BrowserTamer.ps1 скачивает исходный Windows x64 MSI непосредственно из официального выпуска и не изменяет его. Установка выполняется отдельно пользователем. SHA256 из GitHub release проверяет целостность относительно этого источника; статус Authenticode сохраняется отдельно и не подменяется проверкой хеша.

Happ, Claude Desktop, Chrome и Windows — отдельно установленные продукты; их дистрибутивы, учётные данные и подписки не входят в комплект.
